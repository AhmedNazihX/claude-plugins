# 006 — State, cadence, languages, cost policy and testing (bundled defaults)

Date: 2026-10-17 · Status: decided by the user (accepted the proposed defaults)

## Decision

**State.** All state lives in a `.<plugin>/` folder in the project, committed to git:
- `stories/<ID>.md`: one file per story. The frontmatter holds id, title, track, status, deps, files and risk. The
  body holds the context and a DoD written in EARS form ("WHEN … THE SYSTEM SHALL …").
- `board.md`: generated by a script. Never edit it by hand.
- `design.md` and `decisions/`.
- The verdict ledger is runtime state and is gitignored.

**Kanban.** The board columns are Backlog → Ready → Doing → Review → Done, plus Blocked.
- An iteration is a planned batch of at most 8 stories, with no fixed length in days.
- Doing holds at most 3 stories (decision 003).

**Languages.** Scripts and hooks are written in the Python 3 standard library. The workflow is in JavaScript. CI
runs on macOS and Linux from the first story.

**Cost.**
- Token budget per story: Quick 80k, Story 400k.
  - Over budget: a warning in the build table.
  - At 2× the budget: the story stops as BLOCKED.
- The review shows tokens per story and per iteration.
- The baseline context target for the whole plugin is about 2k tokens or less, checked with
  `claude plugin details`.

**Testing.**
- `unittest` for the scripts.
- Payload tests for the hooks.
- The workflow tested with stubbed agents.
- `claude plugin eval` for skill triggering, with free graders only and `--max-cost-usd 2`.

## Why
- Per-story files keep agent reads small. Foreman's single BACKLOG.md was 659 lines.
- The 8-story cap also limits the user's review load.
- The portable CI answers foreman's Linux CI failure.

## Open
- The budgets are first guesses, to be tuned from measured runs.
- The spike checks whether `agent()` reports token usage live. If it doesn't, the 2× stop becomes a cost report
  computed from the transcripts afterwards.
