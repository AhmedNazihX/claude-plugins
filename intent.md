# Intent: Building Orcheteration worfklow plugin for production level software
Author: Ahmed N. Ali (claims operations). Status: draft.
This project's Goal is to Create an orchestiration worflow of agents, skills, scripts, rules, and hooks for working in coding project aimed at production level to be used by Claude code user. It should cover every step from designing tech stack and architecture, planning, work breakdown structure, implementation, reviews, and QA. It should do so in an agile iterative way, with Lean Kanban inspiration. It should be simple for the user to use. it should plan first every step and iteration with the user, and minimize any user blockage unless it is really needed. It should support explaining the steps and options for the user in a simple uncomplicated way that is easy for the user to understand. It should support grilling decisions and talk with the user in the planning phase of each iteration to reach a common uncerstanding about the design and the DoD. It should use git and guard against destructive commands and leaking secrets. It should also use workflows with agents when building stories in the iteration. it should use cutting edge software developing practices.
