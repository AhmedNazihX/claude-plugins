## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: R1 of the design note "Group B: fewer stops, a reason for every ending" (decision 009). A failed check (a failing command, an untagged DoD line, a weak test, an out-of-bounds file) goes into a fix round with the command's output, instead of asking. Check and review fixes share `MAX_FIX_ROUNDS = 2`.
## Reuse
`_run_within_budget` in `accio/bin/accio_lib/checks.py` already returns each command's output; `run` drops it. `checkStop` and `fixRound` in `accio/workflows/brew.js`. The findings format that reviewers already write.
## Definition of Done
- [ ] S-034/1 WHEN a check command fails THE SYSTEM SHALL write `run/<ID>/check-findings.md` with one finding per failing command, ids `check-1…`, holding the command and the last 2,000 characters of its output
- [ ] S-034/2 WHEN a DoD line is untagged THE SYSTEM SHALL add one finding for it to `check-findings.md`
- [ ] S-034/3 WHEN a test is weak THE SYSTEM SHALL add one finding for it to `check-findings.md`
- [ ] S-034/4 WHEN a file is out of bounds THE SYSTEM SHALL add one finding for it to `check-findings.md`
- [ ] S-034/5 WHEN `checkStop` sees failed checks THE SYSTEM SHALL start a fix round with `--fix` pointing at `check-findings.md`, not ask the user
- [ ] S-034/6 WHEN the re-check runs after a fix round THE SYSTEM SHALL mark each earlier check id `resolved` or `open`
- [ ] S-034/7 WHEN check fixes and review fixes together reach 2 rounds THE SYSTEM SHALL stop fixing and block
- [ ] S-034/8 WHEN `brew.js` is searched THE SYSTEM SHALL contain no "Should it be fixed" question
- [ ] S-034/9 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
