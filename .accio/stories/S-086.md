## Context
After this ships: boggart is told how its repros run (copied to `<throwaway worktree>/.accio-repro/<file>` at the
story's head, then at its base, and run from that worktree's root with the config's `breaker` command), so it imports
project code by a path relative to the repro's own folder; and `accio-break <ID> try` refuses a repro whose text names
the main checkout, the worktree root or any story worktree by absolute path, saying how to import instead. We'd know
because a repro that hard-codes the story worktree's path is refused with that message, and a relative-import repro
of a real break fails on head and passes on base.

Why: 7 of the 20 repros saved in `.accio/run/*/boggart/repros/` import by absolute path: S-058's and S-069's from
the story's own worktree, S-057's from the main checkout. `breaker.py` runs each repro in a throwaway worktree at
head and then at base, but a repro that imports the story worktree runs head's code both times, so a real break
also "fails on base", reads `pre-existing` and is dropped; one that imports the main checkout never runs head's code
at all. Nothing told boggart how repros run (`agents/boggart.md` says only "run `accio-break <ID> try <file>`").

Design: (1) boggart.md "Where you write": how a repro runs (the folder it is copied to, the two commits, the working
folder and the configured command), and "import the project's code relative to the repro's folder (for Python,
`Path(__file__).resolve().parents[1]`; for Node, `../<path>`); never an absolute path". (2) `breaker.py` `try` (and
`verify`, which reads saved repros): refuse a repro whose text holds the main checkout's path, the worktree root's
path or `.accio-repro`'s parent as an absolute string, with a plain message; an old saved repro that does is dropped
by verify with that reason, never run. (3) Tests: an absolute-path repro is refused by `try` and dropped by
`verify`; a relative-import repro runs head's code at head and base's code at base (a break that only head has is
kept, not `pre-existing`).
## Definition of Done
- [ ] S-086/1 WHEN boggart's prompt is read THE SYSTEM SHALL say where a repro is copied, at which commits and from which folder it runs, and to import the project's code relative to the repro's own folder
- [ ] S-086/2 WHEN `accio-break <ID> try` gets a repro that names the main checkout, the worktree root or a story worktree by absolute path THE SYSTEM SHALL refuse it with a message saying how to import instead
- [ ] S-086/3 WHEN `verify` meets a saved repro with such a path THE SYSTEM SHALL drop it with that reason, never run it
- [ ] S-086/4 WHEN a relative-import repro breaks code only head has THE SYSTEM SHALL keep it as a break, not mark it pre-existing
- [ ] S-086/5 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
