## Context
After this ships: a story rebuilt after its base branch moved, whose rebase stops on a conflict that house-elf resolves, is checked against its own changes only. We'd know because a test that rebases a story onto a conflicting new base, resolves it and runs the boundary check finds no out-of-bounds files, where today it lists every file that reached the base branch in between.

Why this story: found building Jaza on 2026-10-23 (iterations 6, 7 and 9 there): S-011, S-016 and S-019 were blocked with "it changed files outside the story" listing `.accio/board.md`, `.accio/iterations/*.md`, other stories' files and code another story merged, though each branch sat linearly on the new base and its own diff stayed inside its `files`. Each false block cost a full rebuild (about 100–250k agent tokens per story). Write-up: `~/Workspace/accio-bug-stale-base.md`.

Cause: in `prepare_worktree`, `_record_base(run_dir, onto)` runs only when `rebase` returned no notes. When the rebase stops on a conflict (or one is already in progress), house-elf finishes it with `git rebase --continue`, but `run/<ID>/base` keeps the old base. `checks.trusted_base` accepts it (it is a full sha and an ancestor of `HEAD`, because the new base contains it), so `diff_start` diffs from the old base.

Design: record `onto` after every `rebase` call that returns, notes or not. This is safe because `trusted_base` already checks ancestry: if house-elf aborts the rebase instead, `onto` is not an ancestor of `HEAD`, `trusted_base` returns `None` and `diff_start` falls back to the merge-base with the base branch. `board.resume_point` uses the same `trusted_base`, so a crash mid-rebase resumes at `prepare` (onto not yet an ancestor) and after it at `check`, as today. The base-writes log gets the line through `_record_base`, so the main-snapshot check still forgives it.
## Reuse
`prepare_worktree`, `rebase`, `_record_base` and `recorded_base` in `accio/bin/accio_lib/brief.py`; `trusted_base` and `diff_start` in `accio/bin/accio_lib/checks.py`; the repo fixtures in `accio/tests/test_brief.py` and `accio/tests/test_checks.py`.
## Definition of Done
- [ ] S-067/1 WHEN a story's rebase onto a new base stops on a conflict THE SYSTEM SHALL record the new base in `run/<ID>/base` and append it to the base-writes log
- [ ] S-067/2 WHEN that conflict is resolved and the rebase continued THE SYSTEM SHALL start the story's diff at the new base, so a story whose own changes stay inside its `files` has no out-of-bounds files
- [ ] S-067/3 WHEN the conflicted rebase is aborted instead THE SYSTEM SHALL start the story's diff at the merge-base with the base branch
- [ ] S-067/4 WHEN a rebase finds one already in progress THE SYSTEM SHALL record the base this run asked for, and the cases above hold once it ends
- [ ] S-067/5 WHEN a rebase succeeds without a conflict THE SYSTEM SHALL record the new base as today
- [ ] S-067/6 (no test) checks pass: `python3 tests/run_tests.py`
