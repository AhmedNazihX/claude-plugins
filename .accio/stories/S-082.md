## Context
After this ships: house-elf writes its report to `<worktree root>/.reports/<ID>/build-report.md` (the folder next
to the story worktrees, outside the main checkout), and curfew keeps examiner, professor, auror and boggart out of
it with one folder rule: deny a Read, Grep or Glob whose path is inside that `.reports/` folder or a folder above
it. We'd know because the brief names the new path, owl's summary still quotes the report, and the S-079 tests pass
with the run-folder, git-ignore and file-pattern logic gone.

Why: the S-079 rule kept the report inside `.accio/run/`, where every search from the repo root passes over it, so
curfew had to guess which files a Grep or Glob would reach. It leaked four times in one day (`~` and relative paths,
a search from the root, ripgrep's `--glob` overriding git's ignore rules, then glob syntax curfew didn't model;
`155e754`, `88d71ab`, `bf12b48`). EGM's own advice and the security review's: keep the file out of any folder a
reviewer searches. Reviewers search the main checkout and the story worktree, and neither holds `.reports/`.

Design: (1) `paths.report_path(main, story_id)` = `worktree_root(main) / ".reports" / story_id / summary.REPORT_NAME`;
brief.py and the fix brief give it to house-elf; curfew allows house-elf to write exactly that file (its claimed
story's) and still its worktree. (2) summary.py reads the new path, and falls back to the old
`.accio/run/<ID>/build-report.md` when the new one is missing (a build made by an older accio). brew.js passes
house-elf's reply `report` to headmaster as now. (3) policy `_report_rule` for REPORT_BLIND: deny a Read, Grep or Glob
whose resolved path (or a Glob pattern's fixed start) is inside `<worktree root>/.reports/`, or a Grep or Glob whose
root contains that folder; keep the `~`/relative resolution and the fail-closed denial of an unresolvable path; also
deny a Read of an old `.accio/run/*/build-report.md`. Drop `run_ignored`, `paths.run_ignored`, `_may_name_report`,
`PLAIN_PATTERN` and the git-ignore question in curfew.py. (4) Update the S-079 tests to the new place, and the
policy docstring and DESIGN.
