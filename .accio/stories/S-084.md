## Context
After this ships: examiner, professor, auror and boggart start with `omitClaudeMd: true`, so they review a story
from their own prompt, the review package and the code, without loading the user's global rules or the project's
`CLAUDE.md`. We'd know because each of the four agent files sets it, and a test fails if one stops.

Why: Google's Elephant-Goldfish Model runs every reviewer with `omitClaudeMd: true` ("excludes user/project/local
instruction files"), so its reviews don't depend on whoever runs them. accio's four reviewers load them today: in
this repo that brings rules such as "Test coverage meets 80% minimum", "STOP and use security-reviewer agent" and the
code-review severity table, which pull a reviewer outside the story's DoD and away from accio's own rules
(confidence ≥ 80, ignore style, only the story's change). accio already sets it for librarian, howler, portkey and
prefect. house-elf keeps the project's instructions (it writes the code to the project's conventions), and so does
headmaster (it writes questions for the user, which the user's question format governs). A story's own conventions
belong in the story or the package, where every reviewer sees them the same way.

Design: add `omitClaudeMd: true` to the frontmatter of the four agents; in `test_agents.py`, assert it for them (and
assert house-elf and headmaster don't set it, so the split is deliberate); note in DESIGN where the reviewers' rules
come from.
