## Context
After this ships: `ui_evidence.command` runs in a fresh detached checkout of the story's verified head
(`git worktree add --detach <head>` in a temp folder, removed afterwards), not in the builder's live worktree. So
nothing the builder left in its worktree (uncommitted, ignored, or hidden from `git status` by `assume-unchanged` /
`skip-worktree` flags that code the story runs could set) and nothing changed between the check and the run can
reach the evidence.

Why: an automatic security review on 2026-10-24 (on S-071's dirty-worktree check) found that `git status` misses
ignored files and index-flagged files, and that the check and the run are two moments (TOCTOU). Patching each case
is a list that never ends; a clean checkout closes them all at once.

Cost: every walk builds from a clean folder, so no incremental build cache (for Jaza, a full Swift build each
time; may need the 540 s limit raised or the build split out). Measure on Jaza before choosing; an option is a
`ui_evidence.fresh_checkout` switch.
