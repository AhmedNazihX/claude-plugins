## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: R8 of "Group B: fewer stops, a reason for every ending" (decision 008). curfew allows mad-eye only a fixed list of browser tools under `preview.mcp_prefix` (default `mcp__plugin_playwright_playwright__`): navigate, snapshot, click, type, fill form, select, hover, press key, wait, screenshot, resize, console messages, close.

Defaults set at planning (iteration 13): "the preview's origin" is scheme, host and port of `preview.url`; with no `preview.url`, every `browser_navigate` is denied. A screenshot path is resolved (no `..` escapes, symlinks followed) and allowed only inside `<repo root>/.accio/run/<ID>/mad-eye/`, where `<ID>` is any story ID; a screenshot call with no `filename` is denied, since Playwright would save it outside that folder. Denials use curfew's usual message style and name the rule that denied.
## Reuse
The agent tool rules in `accio/bin/accio_lib/policy.py` and the preview origin from the `preview.url` config (S-045).
## Definition of Done
- [ ] S-046/1 WHEN `accio:mad-eye` calls `browser_navigate` to the preview's origin THE SYSTEM SHALL allow it
- [ ] S-046/2 WHEN `accio:mad-eye` calls `browser_navigate` to any other origin THE SYSTEM SHALL deny it
- [ ] S-046/3 WHEN `accio:mad-eye` takes a screenshot into `run/<ID>/mad-eye/` THE SYSTEM SHALL allow it
- [ ] S-046/4 WHEN `accio:mad-eye` takes a screenshot to a path outside `run/<ID>/mad-eye/` THE SYSTEM SHALL deny it
- [ ] S-046/5 WHEN `accio:mad-eye` calls a browser tool not on the fixed list, such as `browser_evaluate`, `browser_run_code_unsafe` or `browser_file_upload`, THE SYSTEM SHALL deny it
- [ ] S-046/6 WHEN any other agent calls a browser tool THE SYSTEM SHALL deny it
- [ ] S-046/7 WHEN `preview.mcp_prefix` is set THE SYSTEM SHALL use it in place of the default prefix
- [ ] S-046/8 (no test) checks pass: `python3 tests/run_tests.py`
## Review notes
- Rejected at owl: Security: (1) a URL with a backslash or @ in the host part, like http://evil.com\@localhost:3000/, passes the origin check because Python urlsplit reads the host as localhost while a browser goes to evil.com; deny any URL with a backslash, an @ in the netloc, whitespace or control characters before comparing origins. (2) only browser_take_screenshot has its path checked; run the same mad-eye folder check on a filename argument of every browser tool (browser_snapshot and browser_console_messages take one). (3) config.py rejects preview.mcp_prefix because it is not in PREVIEW_KEYS, so S-046/7 cannot be used; add it (config.py joins this story’s files).
