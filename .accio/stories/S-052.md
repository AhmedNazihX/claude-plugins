## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: a security review of S-041 (iteration 13, 2026-10-20). `verify` in `breaker.py` copies a "fixed" or "pre-existing" verdict from the earlier `verdicts.json` without rerunning the repro. So a later fix round that breaks the code again goes unseen, and that file sits in `run/<ID>/boggart/`, the folder boggart may write to, so a wrong write by boggart is trusted. house-elf can't reach it (it works only in its worktree). The fix: rerun every repro marked "fixed" on each `verify`, recheck "pre-existing" against base, and let curfew allow `accio:boggart` writes only under `run/<ID>/boggart/repros/`.
## Reuse
`verify`, `_rerun` and `judge` in `accio/bin/accio_lib/breaker.py`; the per-agent write rules in `accio/bin/accio_lib/policy.py`.
