## Context
After this ships: in a real build (curfew on), a story that touches `ui_globs` gets a mad-eye pass, from the web
preview or from `ui_evidence`, instead of "mad-eye skipped: ... did not run". We'd know because the curfew tests run
the exact commands and writes `brew.js` gives prefect, and they are allowed, while look-alikes are denied.

Why: found in S-068's build report (2026-10-24) and checked on main. `brew.js` has prefect run
`accio-preview <ID> start|stop` (S-047), `accio-preview <ID> evidence-plan` and
`accio-preview <ID> evidence --head <sha>` (S-068), and write `.accio/run/<ID>/ui-steps.txt`. curfew allows none of
it: prefect's script list (`SCRIPTS["checks"]` in `policy.py`) has no `accio-preview`, prefect may write only
`run/questions/*.md`, and even portkey's `accio-preview: {start, stop}` never matches, because the subcommand check
(`bashpolicy.py`, `words[1] in allowed`) reads the story ID, not the action. Tests use stub agents with no curfew, so
nothing caught it; mad-eye has likely never run in an unattended build since S-047 (S-050 checked it by hand). It
fails safe (skip with a note), so it was never a block.

Two smaller gaps from the same report: prefect's Bash tool stops at 600 s and `ui_evidence.timeout` also defaults to
600 s, so a slow walk cuts prefect off with a less clear note; and the steps text mad-eye sends is written by a Haiku
prefect told to copy it unchanged, which a model could still alter.

Design: give `accio-preview` a `script_args` pattern for prefect (as `accio-check` has `PREFECT_CHECK`), allowing only
`accio-preview S-<n> start|stop|evidence-plan` and `accio-preview S-<n> evidence --head <7-40 hex>` (plus whatever
argument the steps check below adds), and add `run/S-*/ui-steps.txt` to prefect's writes. Remove portkey's
`accio-preview` entry if nothing has it run the script (check `brew.js`); else fix its subcommand check the same way.
The steps check: the workflow computes a short checksum of the steps text it got from mad-eye (plain JS, no crypto
needed: the threat is a copying mistake, not an attacker) and passes it to `accio-preview ... evidence`, which
computes it the same way over `ui-steps.txt` and refuses with a clear error when they differ.
## Definition of Done
- [ ] S-070/1 WHEN prefect runs `accio-preview <ID> start`, `stop`, `evidence-plan` or `evidence --head <sha>` (the exact forms `brew.js` gives it) under curfew THE SYSTEM SHALL allow it
- [ ] S-070/2 WHEN prefect runs `accio-preview` with any other action, a bad story ID, a bad head, an extra argument, or chained with another command THE SYSTEM SHALL deny it
- [ ] S-070/3 WHEN prefect writes `.accio/run/<ID>/ui-steps.txt` under curfew THE SYSTEM SHALL allow it, and SHALL still deny any other path outside `run/questions/*.md`
- [ ] S-070/4 WHEN `ui-steps.txt` differs from the steps text mad-eye sent THE SYSTEM SHALL not run the evidence command and SHALL skip mad-eye with a note saying the steps file was changed
- [ ] S-070/5 WHEN `ui_evidence.timeout` is not given THE SYSTEM SHALL default it to 540 seconds, and SHALL refuse a config `timeout` above 540 (prefect's Bash tool stops at 600)
- [ ] S-070/6 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
