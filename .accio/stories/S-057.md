## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: iteration 17's build blocked S-043 on an accio hiccup, not a real decision. Its checks failed once (check-1: `accio/agents/boggart.md` was outside the story's `files`), the judge ruled (`run/S-043/ruling-r1.md`) that the change stays, and the next builder could not claim the story: "S-043 is held by agent ad887b2048e9b31e3", and `accio-claim S-043` was denied in both forms. `claims.json` still held that agent's claim after the build. Only `accio-brief` releases a claim (S-015, `runlock.release_claim` before a new brief), so some path in `brew.js` starts a new house-elf after a ruling without a new brief. The builder should find that path from `brew.js` and the run folder (`.accio/run/S-043/`: `fix-1/`, `fix-brief.md`, `ruling-r1.md`) and fix it at the root.
## Reuse
`runlock.release_claim` and `accio-brief`'s release step (S-015); the build, ruling and fix-round paths in `accio/workflows/brew.js`; the workflow test harness in `accio/tests/workflow/`.
## Definition of Done
- [ ] S-057/1 WHEN the build starts a new house-elf for a story after a ruling or a fix brief THE SYSTEM SHALL release the story's earlier claim first, so the new builder's `accio-claim <ID>` succeeds
- [ ] S-057/2 WHEN a build ends THE SYSTEM SHALL leave no claim in `claims.json` for a story of that build
- [ ] S-057/3 WHEN two builders of different stories run at once THE SYSTEM SHALL still refuse one builder's claim on the other's story
- [ ] S-057/4 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
