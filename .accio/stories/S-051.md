## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: a race in S-045's `accio-preview`, shipped in 0.7.0. It failed `test_preview.py::test_S_045_2_second_start_waits_on_the_lock_until_the_first_is_stopped` in the 0.7.0 CI run on macOS (run 39425764883) and blocked S-042 in iteration 13. In `stop()`, `_kill_group` ends story A's server first; the lock still names A's dead pid, so `_try_lock` sees it as stale and story B's waiting `start` takes the lock and starts on the same port; then A's `_free_port` finds B's new listener and kills it ("the preview command exited with -15"). Found by S-042's builder (`.accio/run/S-042/build-report.md`) and a side agent on 2026-10-20.

The fix: `stop` must hold the lock (under `runlock.guard`) from before it kills A's group until A's port is free and the lock file is removed, so no other start can take the lock in between; and `_free_port` must never kill a listener while another story holds the lock.
## Reuse
`runlock.guard`, `_try_lock`, `_kill_group`, `_free_port` and `_clear` in `accio/bin/accio_lib/preview.py`; the two-story test in `accio/tests/test_preview.py`.
## Definition of Done
- [ ] S-051/1 WHEN story A's preview is stopped while story B's `start` waits on the lock THE SYSTEM SHALL let B take the lock only after A's port is free and A's lock is removed
- [ ] S-051/2 WHEN another story holds the preview lock THE SYSTEM SHALL not kill any listener on the port in that story's place (a `stop` for a story that no longer holds the lock frees no port)
- [ ] S-051/3 WHEN `test_S_045_2_second_start_waits_on_the_lock_until_the_first_is_stopped` runs 20 times in a row THE SYSTEM SHALL pass every time (a new test that loops the two-story case)
- [ ] S-051/4 (no test) checks pass: `python3 tests/run_tests.py`
