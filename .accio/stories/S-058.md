## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: S-043's own risk note (iteration 17) and a side-agent note on 2026-10-21. Whether boggart runs depends on the `code` and `breaker` flags of the review package. `accio-brief --review` prints them, but they reach `brew.js` through the package step's agent (portkey, on Haiku), and `PACKAGE_SCHEMA` doesn't require them. If that agent leaves a flag out, `boggartStage` reads it as false and skips boggart, and nothing logs why: the story looks fully checked though nothing tried to break it.

The fix: `PACKAGE_SCHEMA` requires `code` and `breaker`, so a reply without them is retried like any malformed reply, and a skip because a flag is false says which flag in the story's note, so owl shows it.
## Reuse
`PACKAGE_SCHEMA`, `packageFor` and `boggartStage` in `accio/workflows/brew.js`; the stub agents in `accio/tests/workflow/stub.mjs`.
