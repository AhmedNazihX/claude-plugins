## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: R4 of "Group B: fewer stops, a reason for every ending". boggart is a new Sonnet agent with `accio/docs/research/breaker.md`'s checklist: read the claims, list 3-6 risks, at most 3 charters and about 5 properties, judge only by a written claim, never edit. It reads the review package (story, DoD, diff), not house-elf's report, writes repros to `run/<ID>/boggart/` and may run `accio-break <ID> try <file>`.

Defaults set at planning (iteration 13): `boggart.md` tells boggart to start every repro with the two comment lines S-041's runner reads, `claim: <quoted text>` and `source: <DoD id like S-012/3, or file:line>`. Each eval case under `accio/evals/boggart/` is a folder with a story file, a diff and an `expected.md` naming the planted break (or "none"), laid out like the other eval folders.
