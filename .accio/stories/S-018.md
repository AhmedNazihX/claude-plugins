## Context
After this ships: when CI fails after owl's push, howler's report says whether the cause lies inside the pushed range
or outside it, instead of "the range is unknown". We'd know because `accio-owl push-ok` prints the old tip and owl's
howler prompt carries it.

Found in iteration 4's build of S-003 (builder's risk note): howler's prompt asks for the previous pushed commit
`<prev>`, "the old tip of the base branch" (`accio/agents/howler.md` line 10), but `push_ok` in
`accio/bin/accio_lib/owl.py` returns only `{"base", "sha"}`, so owl's step 6 has no `<prev>` to give. Howler's step 6
range check needs it.

The old tip is what the main checkout knows of the remote's base branch before the push:
`git rev-parse --verify --quiet refs/remotes/origin/<base>`, read inside `push-ok` (after the push, git moves that
ref, so it must be read before). When that ref does not exist (never fetched, or a new branch), `prev` is `null`, and
owl tells howler there is no previous pushed commit; howler then takes the commit of step 5's previous run as `<prev>`
when it has one, and otherwise reports the range as unknown.
