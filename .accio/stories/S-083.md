## Context
After this ships: `accio-board drift` lists each done story whose testable DoD line (one not marked `(no test)`) no
test file in the main checkout carries any more, and map shows that list in one line per story. We'd know because
deleting or renaming a tagged test of a done story makes map name that story and the line.

Why: Google's Elephant-Goldfish Model runs a periodic drift report between checked-in specs and the live code. In
accio every DoD line is tied to a test by its tag, and `accio-check` checks that while a story is built, but
nothing checks later: a direct fix on main (`cf216ee`, `f8985df`, `0ea746e` in October) or a later story can delete
or rename a test, and the done story's promise goes untested without anyone seeing it. A script finds this; no model
is needed.

Design: (1) `accio-board drift [--json]`: for each story with status `done`, run `checks.untagged(story.dod,
checks.test_texts(main root))` (the same tag rules as the build: `S-001/3` or `S_001_3`, fixtures don't count); print
`S-012/2 S-012/4 · <title>` per story with lost lines, or `no drift` when none; `--json` gives
`{"drift": [{"id", "title", "lines": [...]}]}`. It writes nothing and runs while a build runs. (2) map: run it after
`status` and show its lines (or nothing when `no drift`), and in the next-step line say a lost test is fixed by a
new story or a direct fix. (3) Stories done before tags existed may show up: that is the point; no exemption list.
## Definition of Done
- [ ] S-083/1 WHEN a done story's testable DoD line has no test carrying its tag THE SYSTEM SHALL list that story and line in `accio-board drift`
- [ ] S-083/2 WHEN every done story's testable lines are carried by tests, or a line is `(no test)`, or the story isn't done, THE SYSTEM SHALL not list it, and print `no drift` when nothing is lost
- [ ] S-083/3 WHEN `accio-board drift --json` runs THE SYSTEM SHALL give `{"drift": [{"id", "title", "lines"}]}` and write nothing
- [ ] S-083/4 WHEN map's skill is read THE SYSTEM SHALL run `accio-board drift` and show its lines
- [ ] S-083/5 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
