## Context
After this ships: code a story runs (its tests, its build, its evidence command) can't make accio diff the story from
a later commit, so it can't hide files from the glob-based checks, the review package or S-069's evidence-files check.
We'd know because a test that writes the story's own commit into `.accio/run/<ID>/base` gets the true start back.

Why: an automatic security review on 2026-10-24 flagged `checks.diff_start`. It reads the base `accio-brief` recorded
in `.accio/run/<ID>/base`, and `checks.trusted_base` refuses a record that isn't a full commit id or an ancestor of
the story's HEAD. But the story's HEAD is an ancestor of itself, and code the story runs can reach the main checkout's
run folder, so writing HEAD (or any commit the story made) there gives an empty or shorter diff. Not seen in practice:
it needs a story whose own code writes the file.

Design, to check first: (a) whether the main-checkout snapshot (`main-snapshot.json`) already catches a write to
`run/<ID>/base` during a build; if so, this story is a test that proves it, plus a comment at `trusted_base`.
(b) Otherwise, also refuse a recorded base that the story made: it must be an ancestor of the base branch, or, for a
stacked story, of its parent story's branch (S-069 was stacked on S-070, whose head was not on main yet), and fall back
to the merge-base as today.
## Definition of Done
- [ ] S-072/1 WHEN `.accio/run/<ID>/base` names the story's HEAD or another commit only the story's branch has THE SYSTEM SHALL not use it as the diff start (or the build stops on the snapshot, if (a) holds)
- [ ] S-072/2 WHEN a stacked story's recorded base is its parent story's head THE SYSTEM SHALL still use it
- [ ] S-072/3 WHEN the recorded base is the base branch's commit from prepare time (main moved on since) THE SYSTEM SHALL still use it
- [ ] S-072/4 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
