## Context
After this ships: a build in a new or freshly set-up repo can't silently skip its tests, a rebuilt story never hands back its old unreviewed work as done, and a direct fix to accio gets accio's own reviewers. We'd know because the next iteration has no stop caused by any of these three, and a direct fix's review comes from `accio-brief --review` instead of a hand-written package.

This story is design "Lessons from iteration 1", part 2 (R2), so S-010's refusal never stops a first build. wand's setup step proposes the commands and writes the ones the user keeps.
## Reuse
`accio/skills/wand/SKILL.md` setup step; `.accio/config.json` `checks` key.
## Definition of Done
- [ ] S-011/1 WHEN the repo has `.github/workflows/*.yml` THE SYSTEM SHALL propose each of its `run:` lines whose command contains `test`, `lint`, `check`, `pytest`, `unittest` or `build`
- [ ] S-011/2 WHEN the repo has a `package.json` with scripts THE SYSTEM SHALL propose the test and lint scripts
- [ ] S-011/3 WHEN the repo has a pytest folder THE SYSTEM SHALL propose the matching test command
- [ ] S-011/4 WHEN the repo has none of these THE SYSTEM SHALL propose nothing and say so
- [ ] S-011/5 (no test) by hand: wand's setup shows the proposals and writes only the ones the user keeps into `config.json`
- [ ] S-011/6 (no test) checks pass: `cd accio && python3 -m unittest discover -s tests`
