## Context
After this ships: a reader of accio's README sees which Claude model each agent runs on, and the table can't drift
from the agent files. We'd know because the README's agent table has a Model column and a test compares it with
every `accio/agents/*.md`.

The user asked for it on 2026-10-19. Today the agent table (`accio/README.md` lines 28-40, columns Agent, Role, What
it does) has no models, and has no row for `howler` (added by S-002). The model is each agent file's `model:`
frontmatter line: wandmaker opus; auror, examiner, headmaster, house-elf, professor, quill, seeker sonnet; howler,
librarian, portkey, prefect haiku. Write the model as the frontmatter word (`opus`, `sonnet`, `haiku`). One sentence
under the table says why: Haiku for the clerks that run scripts and read CI, Sonnet for building and reviewing, Opus
for the architect.

The test is a new file so it doesn't collide with other stories' edits to `test_agents.py`.
## Reuse
The agent table in `accio/README.md`; the frontmatter reading in `accio/tests/test_agents.py` (copy the small parse,
