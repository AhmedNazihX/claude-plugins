## Context
After this ships: a build in a new or freshly set-up repo can't silently skip its tests, a rebuilt story never hands back its old unreviewed work as done, and a direct fix to accio gets accio's own reviewers. We'd know because the next iteration has no stop caused by any of these three, and a direct fix's review comes from `accio-brief --review` instead of a hand-written package. This story is part 6 of "Lessons from iteration 1" (R6): the main snapshot forgives another story's `run/<ID>/base` only when accio's own prepare step wrote it during the run, not any change to it (accio 0.1.5 forgives every change; the push security review flagged it). This keeps the tamper check whole with parallel builds.

The log: `.accio/run/base-writes.log`, append-only, one line per base write, in the form `<ID> <full sha>`. `accio-brief` appends a line each time it writes `run/<ID>/base`. The snapshot watches the log like the other run control files, but a log change counts only when the log before is NOT a prefix of the log after: lines appended are fine, a removed or rewritten line counts as a change. Another story's base change is forgiven only when the log after holds a line for that story with the base file's new content.
## Reuse
`accio/bin/accio_lib/checks.py`: `_another_storys_base` and `compare` (the forgiveness today), `BASE_NAME`, and `WATCHED_RUN_FILES` / `_watched_run_files` (about lines 63 and 236), which list the watched run files. Register the log's name as a constant next to `WATCHED_RUN_FILES`, and have `accio/bin/accio_lib/brief.py` (which writes each `run/<ID>/base`) import it from there. The log lives in `.accio/run/`, which the snapshot already watches.
## Definition of Done
- [ ] S-016/1 WHEN `accio-brief` writes a story's `run/<ID>/base` THE SYSTEM SHALL append the line `<ID> <full sha>` to `.accio/run/base-writes.log`, keeping every earlier line
- [ ] S-016/2 WHEN another story's `run/<ID>/base` changed and the log after holds a line for that ID with the base file's new content THE SYSTEM SHALL forgive the change
- [ ] S-016/3 WHEN another story's `run/<ID>/base` changed and the log after has no line for that ID with the new content THE SYSTEM SHALL report it as a change
- [ ] S-016/4 WHEN the log after only adds lines to the log before (another story's prepare appended during the run) THE SYSTEM SHALL NOT report the log as a change
- [ ] S-016/5 WHEN the log before is not a prefix of the log after (a line removed, rewritten or the log deleted) THE SYSTEM SHALL report the log as a change
