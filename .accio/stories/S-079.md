## Context
After this ships: examiner, professor and auror review a story from its story file, its diff and its tests only,
as boggart already does; the review package no longer points them at house-elf's `build-report.md`, and curfew
refuses a reviewer that tries to read it. We'd know because a review package never names the report, and a reviewer's
Read of `run/<ID>/build-report.md` is denied with the reason.

Why: Google's Elephant-Goldfish Model (github.com/google/elephant-goldfish-model, read 2026-10-25) rests on one
rule: a reviewer who reads the author's account of the work tends to agree with it, so reviewers read only the spec
and the code. accio follows it for boggart (`agents/boggart.md`: "not house-elf's report or its reasoning: you judge
the code, not the builder's account of it"), but `review.py` `_render` gives the other three reviewers
"the implementer's report: `run/<ID>/build-report.md`" as a source. That report holds house-elf's own risks and what
it thinks it changed, which is exactly what a fresh reviewer should find for itself.

Design: (1) `_render`'s `source_line` names only the story file; the direct-fix package (`package_fix`) keeps its
line. (2) examiner, professor and auror's prompts say, like boggart's, that they never read house-elf's report or its
reasoning. (3) curfew, for examiner, professor, auror and boggart: deny `Read` of any `build-report.md` under
`.accio/run/`, and deny `Grep`/`Glob` whose path is inside `.accio/run/<ID>/` or whose pattern names
`build-report`, with a reason that says why (rule: builder's report). Their findings files and the package stay
readable. house-elf, headmaster (it rules on a finding house-elf refused in its report), prefect and the main session
(owl's summary quotes the report) are unchanged. `.accio/run/` is git-ignored, so a Grep from the repo root doesn't
reach it.
## Definition of Done
- [ ] S-079/1 WHEN accio writes a story's review package, first review or fix round, THE SYSTEM SHALL name the story file and never the implementer's report
- [ ] S-079/2 WHEN examiner, professor, auror or boggart reads a story's `build-report.md`, or greps or globs inside `.accio/run/<ID>/` or for `build-report`, THE SYSTEM SHALL deny it with the reason
- [ ] S-079/3 WHEN examiner, professor, auror or boggart reads its review package or findings file THE SYSTEM SHALL allow it, and house-elf, headmaster and prefect keep their access to the report
- [ ] S-079/4 WHEN examiner's, professor's or auror's prompt is read THE SYSTEM SHALL tell it never to read house-elf's report or its reasoning
- [ ] S-079/5 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
