## Context
After this ships: a stacked story's recorded base must equal its parent's head as `accio-brief` saw it (pinned from
the main checkout), not merely be an ancestor of the parent's live `story/<dep>` branch. So code a story runs can't
move the parent's branch onto a story commit to shorten the story's diff.

Why: S-072 (2026-10-24) accepts a recorded base that is an ancestor of the base branch or of a dep's `story/<dep>`
branch. Its build report and an automatic security review after the 0.11.0 push both noted that story branches aren't
watched by the main snapshot (they move with every checkpoint), so moving a dep branch still passes. Needs a story's
own code to rewrite another branch on purpose; not seen in practice.
## Definition of Done
- [ ] S-074/1 WHEN `accio-brief` prepares a stacked story THE SYSTEM SHALL record each parent's head beside the base, in the main checkout's run folder
- [ ] S-074/2 WHEN a stacked story's recorded base is not one of those pinned heads (and not an ancestor of the base branch) THE SYSTEM SHALL not use it as the diff start
- [ ] S-074/3 WHEN a parent's branch moved after the pin THE SYSTEM SHALL still diff the child from the pinned head
- [ ] S-074/4 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
