## Context
After this ships: `/accio` goes from a new design note straight to sort, every flag that decides whether a review step runs comes from a script, and mad-eye can't quietly wander off the preview. We'd know because after the next wand note `accio-board next` says `sort`; `brew.js` asks portkey to compute no flag itself; a test shows an off-origin page after a click is hidden from mad-eye and fenced; auror's checklist has the two-parsers line; and the next story that adds an agent lists `accio/README.md` in its `files`.

Why this story: requirements L3 and L4 of "Group B leftovers". auror missed a URL parser bypass in S-046, and builds hit an out-of-bounds `accio/README.md` when a story adds an agent (`test_readme.py` counts agents against README rows).

Design: one bullet in the auth-and-security checklist: when one part checks a URL or path and another reads it again (browser, server, file system), try inputs the two may read differently (`\`, `@`, `%2f`, `%5c`, `..`), for example `http://evil.com\@host:port/`. quill.md's `files` rule: a story that adds a file a test counts lists that file too (each `accio/agents/*.md` needs its row in `accio/README.md`). Sort's backlog check asks examiner to look for it.
## Reuse
The existing checklist bullets and the `files` rule in `accio/agents/quill.md`; the checks in `accio/tests/test_agents.py`.
