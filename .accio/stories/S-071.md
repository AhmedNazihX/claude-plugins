## Context
After this ships: when mad-eye or boggart finds a problem in a real build (curfew on), the story goes to a fix round
instead of the build stopping with "Writing the ... findings failed. Try again?", and a story can't get past S-069's
evidence-files check with uncommitted files or a different letter case.

Why, findings writes: found in S-070's build report (2026-10-24) and checked on main. brew has prefect write
`.accio/run/<ID>/mad-eye-findings.md` (`writeSeenFindings`) and `.accio/run/<ID>/boggart-findings.md`, but prefect's
writes in `policy.py` are only `run/questions/*.md` and `run/S-[0-9]*/ui-steps.txt`. The boggart gap is older (S-052)
and shows only when boggart finds a break inside the DoD in a real build; the mad-eye one could not show before
S-070, because mad-eye never ran.

Why, the evidence-files check (`preview.evidence_files`, S-069): an automatic security review on 2026-10-24 found two
ways past it. 1) It lists only committed changes (`git diff <start> HEAD`), but the evidence command runs on the
worktree as it is, so uncommitted or untracked changes to the walk code make evidence unseen. 2) It matches globs
with letter case, but macOS file names aren't case-sensitive (Jaza builds on macOS), so `sources/uiwalk/x.swift`
can slip past a `Sources/UIWalk/**` glob.
## Definition of Done
- [ ] S-071/1 WHEN prefect writes `.accio/run/<ID>/mad-eye-findings.md` or `.accio/run/<ID>/boggart-findings.md` under curfew THE SYSTEM SHALL allow it, and SHALL still deny other paths (tested through the hook, as S-070's curfew tests are)
- [ ] S-071/2 WHEN the story's worktree has uncommitted, staged or untracked files at evidence time THE SYSTEM SHALL not run the evidence command and SHALL skip mad-eye with a note naming the files
- [ ] S-071/3 WHEN a changed path matches an `evidence_globs` pattern apart from letter case THE SYSTEM SHALL count it as touching the pattern (this check only; other glob uses keep their behaviour)
- [ ] S-071/4 (no test) checks pass: `python3 tests/run_tests.py` and `node --test 'tests/workflow/**/*.test.mjs'`
