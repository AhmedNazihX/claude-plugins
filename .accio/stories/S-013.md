## Context
After this ships: a build in a new or freshly set-up repo can't silently skip its tests, a rebuilt story never hands back its old unreviewed work as done, and a direct fix to accio gets accio's own reviewers. We'd know because the next iteration has no stop caused by any of these three, and a direct fix's review comes from `accio-brief --review` instead of a hand-written package.

This story is design "Lessons from iteration 1", part 4 (R4): `accio-brief --review --fix-branch <branch> --acceptance <file>`, the same package as for a story with the acceptance list in place of the DoD.
## Reuse
The existing review-package code in `accio/bin/accio_lib/review.py` and its template `accio/bin/accio_lib/templates/review-package.md`.
## Definition of Done
- [ ] S-013/1 WHEN `accio-brief --review --fix-branch <branch> --acceptance <file>` runs for a branch that is not a story THE SYSTEM SHALL write a review package
- [ ] S-013/2 WHEN the package is written THE SYSTEM SHALL hold the diff path, the acceptance list in place of the DoD, and the findings paths for professor, auror and examiner
- [ ] S-013/3 WHEN the acceptance file is missing or empty THE SYSTEM SHALL exit with a plain message and write nothing
- [ ] S-013/4 WHEN `accio-brief --review` runs for a story THE SYSTEM SHALL behave as today
- [ ] S-013/5 (no test) checks pass: `cd accio && python3 -m unittest discover -s tests`
