## Context
After this ships: when a repo's `.accio/config.json` has no `mutation` key, wand's setup names the mutation tool
that fits the repo's language and asks once: "Your tests aren't checked for weak spots. Turn on the mutation check
with <tool>?" No writes `"mutation": false`, so accio never asks again; yes gives the setup steps. While the key is
missing, owl's summary starts with one line saying the build's tests weren't checked for weak spots, and how to turn
the check on. We'd know because a repo with no `mutation` key gets the question in wand and the line in owl, and a
repo with `"mutation": false` or a command gets neither.

Why: decision 011's mutation check only runs when `mutation.command` is set, and nothing ever says so. Setup never
mentions it, and `accio-check`'s "not audited" stops in prefect's reply, so owl never shows it. Every repo accio
builds in today, this one and Jaza included, is unchecked without the user knowing.

Design: (1) `bin/accio_lib/mutationfinder.py`, like `checkfinder.py` (S-011): reads the repo's marker files and
prints the tool that fits, or "none known"; it writes nothing. Markers: `pyproject.toml`, `setup.py` or `*.py` →
`mutmut`; `package.json` → Stryker; `Cargo.toml` → `cargo-mutants`; `Package.swift` or `*.xcodeproj` → Muter.
More than one language: name each. (2) wand step 1, after **Check commands**: when config has no `mutation` key, run
the finder; when it names a tool, ask the question above (one question, its own message). On no, write
`"mutation": false` (Edit). On yes, say the steps in plain words and write nothing: install the tool as a dev
dependency; give it a small wrapper that takes the story's diff file, mutates only the changed lines, and prints
each surviving mutant on its own line starting `file:line`; set `mutation.command` to that wrapper with `{diff}`
(decision 011). "none known": say in one line that no mutation tool is known for this repo, and don't ask. wand's
`allowed-tools` lists the finder. (3) `config.py`: `mutation` also accepts `false` (declined); `false` and a missing
key both mean "not audited" to `accio-check`, as now. (4) `summary.py`: when the key is missing, `owl.md` starts
with "Tests not checked for weak spots: the mutation check is off. Set `mutation.command` in .accio/config.json, or
`"mutation": false` to stop this note." Nothing when it's `false` or set.

Later, not here: accio ships the wrappers, so "yes" turns the check on by itself. That needs each tool's output
format checked first.
