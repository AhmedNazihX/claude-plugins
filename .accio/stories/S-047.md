## Context
After this ships: a build stops for the user only for a real decision, and every finding, block and break leaves a reason. We'd know because over the next two iterations no story blocks with "Should it be fixed and built again?" or on a one-off accio hiccup; each `.accio/iterations/<N>.md` has one line per finding and block saying how it ended; every boggart break that reached a fix round came with a repro that failed twice on head; owl reports a cost for every build; and the guard and allow-list tests pass.

Why this story: R8 and R9 of "Group B: fewer stops, a reason for every ending" (decision 008). mad-eye is a new Sonnet agent that opens the preview, walks each visible DoD line, saves one screenshot per line to `run/<ID>/mad-eye/`, writes `mad-eye-findings.md`, and never edits. It runs after boggart's step, only when the diff touches `ui_globs`. Its findings go to the fix round. Evidence in this repo is limited: it has no UI, so first real evidence comes from another repo.

The spike S-044 (`accio/docs/research/spike-s-m2-m3.md`, verdict go) shapes this story. Finding 4: an agent's `tools:` frontmatter limits it to the tools listed, so mad-eye's `tools:` lists exactly the allowed browser tools (curfew is the second wall). Finding 1: screenshots need an absolute path inside the repo. Finding 3: refs go stale after a scoped snapshot.
## Reuse
The review-step and fix-round code in `accio/workflows/brew.js`; `accio-preview` (S-045, S-049); the missing-tools outcome recorded by S-044.
## Definition of Done
- [ ] S-047/1 WHEN `config.json` sets `ui_globs` THE SYSTEM SHALL read it as a list of path globs, and WHEN it is unset THE SYSTEM SHALL read it as an empty list
- [ ] S-047/2 WHEN the diff touches no file matching `ui_globs` THE SYSTEM SHALL not call mad-eye
- [ ] S-047/3 WHEN the diff touches a file matching `ui_globs` but config has no `preview` or no `"test_data": true` THE SYSTEM SHALL log a skip naming the missing field
- [ ] S-047/4 WHEN the mad-eye call fails with the missing-browser-tools outcome that S-044 recorded in `accio/docs/research/spike-s-m2-m3.md` THE SYSTEM SHALL log a skip
- [ ] S-047/5 WHEN mad-eye runs THE SYSTEM SHALL call `accio-preview <ID> start` first and `accio-preview <ID> stop` after it
- [ ] S-047/6 WHEN mad-eye fails or returns an error THE SYSTEM SHALL still call `accio-preview <ID> stop`
- [ ] S-047/7 WHEN mad-eye reports findings in `mad-eye-findings.md` THE SYSTEM SHALL send them to the fix round
- [ ] S-047/8 WHEN `mad-eye.md` is read THE SYSTEM SHALL name the Sonnet model, list only the fixed browser tools plus read tools with no edit tool, and say it logs in only with the account in `preview-login.json`
- [ ] S-047/9 WHEN the README's mad-eye section is read THE SYSTEM SHALL say plainly that the preview must use test data and test keys, that `test_data` is the user's word and accio can't check it, and that login details come from environment variables
- [ ] S-047/10 (no test) checks pass: `python3 tests/run_tests.py`, `node --test 'tests/workflow/**/*.test.mjs'`
- [ ] S-047/11 WHEN mad-eye saves a screenshot THE SYSTEM SHALL use an absolute path under `.accio/run/<ID>/mad-eye/` (the MCP server refuses paths outside the repo, and a relative name lands in the repo root; spike finding 1)
- [ ] S-047/12 WHEN `mad-eye.md` is read THE SYSTEM SHALL tell mad-eye to take a full page snapshot before each click (a click after a scoped snapshot failed with a stale ref; spike finding 3)
- [ ] S-047/13 WHEN the README's mad-eye section is read THE SYSTEM SHALL tell the user to start the Playwright MCP server with `--allowed-origins <preview origin>`, since curfew checks only `browser_navigate` and a click can still follow a link off the preview (security review of S-046, iteration 13)
