# S-912 Average of a list

## Context
Reports show the mean of the numbers in a column. A column can be empty.

## Definition of Done
- [ ] S-912/1 WHEN `average(values)` is called with numbers THE SYSTEM SHALL return their mean
- [ ] S-912/2 WHEN `values` is empty THE SYSTEM SHALL return 0.0
